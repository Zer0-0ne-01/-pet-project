# Cardsharp — многопользовательская 2D-игра на Python

Учебный проект по созданию многопользовательской 2D-игры на чистом Python для 2–3 игроков. Игра вдохновлена RAUNDS и использует клиент-серверную архитектуру: сервер хранит состояние игры, а клиенты отправляют действия и отрисовывают происходящее. Стек — Python, Pygame и сокеты. Цель — собрать рабочий MVP и поиграть с друзьями.

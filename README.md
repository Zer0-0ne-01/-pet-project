# Shuffling

Учебный 2D-проект на Python и Pygame: сетевой free-for-all на 2–4 игроков.

## Сетевая игра

- Авторитарный UDP-сервер: движение, прыжки, здоровье, попадания, отбрасывание и смерть рассчитываются на сервере.
- Раунды автоматически начинаются после подключения второго игрока.
- Победитель раунда получает очко; каждые две победы одного игрока заполняют квадрат, даже если между ними выигрывал соперник. Только после заполнения квадрата проигравшие выбирают улучшение, затем начинается следующий раунд. Счёт и улучшения сохраняются и продолжают накапливаться.
- После заполнения квадрата все проигравшие выбирают по одному улучшению из трёх случайных карт; оно сохраняется до конца матча. Редкие карты выпадают реже обычных. Если игрок не выбрал карту за 20 секунд, сервер назначит одну из показанных карт случайно.
- В пуле улучшений есть усиление урона и брони, двойной прыжок, здоровье, скорость снарядов, яд, взрывы и рикошеты. Улучшения можно собирать уровнями до указанного максимума.
- В оружии магазин на три выстрела; затем требуется перезарядка 1,5 секунды. Над оружием показаны оставшиеся патроны и ход перезарядки. Улучшения скорости стрельбы изменяют также время перезарядки магазина.
- Снаряды летят по баллистической параболе под действием гравитации; столкновения с платформами учитывают траекторию и отскоки.
- Четыре арены с разными платформами и палитрами меняются каждый раунд; одна и та же карта не выпадает два раунда подряд.
- Перед подключением задаются ник и цвет; в общем лобби цвет можно поменять. Сервер отклоняет дубли цветов. Хост запускает матч вручную после сбора игроков.
- Перед подключением можно выбрать один из двух вариантов глаз, рта и оружия. Выбор оружия меняет только внешний вид и не влияет на характеристики или стрельбу.
- Игровое поле, меню и лобби оформлены в стиле неоновой аркады: статичный градиентный фон с перспективной сеткой во время игры, контрастные платформы, персонажи с цветными силуэтами, акцентные панели и перекрестие прицела.
- Счёт показан в правом верхнем углу только цветными фигурами: одна победа даёт временный треугольник, две победы заполняют постоянный квадрат. Треугольники сохраняются при победе соперника; когда игрок заполняет квадрат, треугольники проигравших сбрасываются после выбора улучшений. Квадраты остаются на протяжении всей игры.
- Ходьба, прыжки, приземления и отдача анимируются локально; снаряды получают свечение, а попадания и исчезновения сопровождаются короткими геометрическими вспышками.
- Компактный HUD показывает здоровье, патроны и перезарядку; статичный фон, подписи и эффекты свечения кэшируются для стабильной производительности.
- Клиент повторяет запрос подключения, а сервер отвечает на повторные запросы; отключившиеся игроки удаляются по таймауту.
- Управление: `A/D` — движение, `Space` — прыжок, ЛКМ — выстрел. В фазе драфта кликните карту или нажмите `1`, `2` или `3`. `Esc` — выход.

Это небольшой учебный MVP, а не точная копия ROUNDS: сейчас есть только подключение по IP и одна базовая атака с магазином на три патрона.

## Установка

Нужен Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pygame
```

## Запуск

Из корневой папки проекта откройте два терминала.

1. На компьютере, который будет хостом, запустите сервер:

   ```powershell
   python -m server.server
   ```

2. На каждом игровом компьютере запустите клиент:

   ```powershell
   python -m client.main
   ```

В меню выберите «Сетевая игра», введите IP-адрес, ник и цвет, затем ждите в лобби. Первый подключившийся игрок становится хостом и запускает матч кнопкой «Запустить матч», когда подключились как минимум два человека. На компьютере с сервером в форме подключения можно оставить адрес пустым. Все игроки должны использовать один и тот же UDP-порт `9999`; разрешите Python принимать UDP-соединения в брандмауэре хоста.

Для игры через интернет, помимо IP-адреса, может потребоваться проброс UDP-порта `9999` на роутере. При CGNAT входящее подключение снаружи обычно недоступно без VPN/виртуальной LAN или отдельного публичного сервера. Проект пока не предоставляет matchmaking или шифрование трафика — подключайтесь только к доверенным серверам.

Сетевой клиент также можно запустить напрямую:

```powershell
python -m client.client --host 127.0.0.1 --port 9999 --name Player
```

## Структура  

- `client/` — меню и сетевой клиент.
- `server/` — серверная физика и игровая логика сетевого режима.
- `shared/` — общие настройки, протокол и геометрия уровня.

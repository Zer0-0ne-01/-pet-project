# Cardsharp — многопользовательская 2D-игра на Python

Учебный проект по созданию MVP-игры в жанре, вдохновлённом **RAUNDS**, для 2–3 игроков.  
Цель — реализовать клиент-серверную 2D-игру на чистом Python с использованием Pygame и сокетов.

🚧 В разработке.

## 🎮 Планируемые возможности

- Сетевая игра на 2–3 человека.
- Клиент-серверная архитектура с авторитетным сервером.
- Управление персонажем с клавиатуры.
- Столкновения, здоровье, очки.
- Простое меню, экран победы/поражения и HUD.
- Базовая синхронизация позиций игроков по сети.

## 🛠️ Технологии

- **Python 3.10+**
- **Pygame** — графика, ввод, звук.
- **socket** — сетевое взаимодействие (UDP/TCP).
- **JSON** — формат обмена сообщениями между клиентом и сервером.
- **Git / GitHub** — контроль версий.

## 📦 Установка

1. Клонируй репозиторий:

   ```bash
   git clone https://github.com/[твой_ник]/[название_репозитория].git
   cd [название_репозитория]
   ```

2. Создай виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активируй его:

   - **Windows:**
     ```bash
     venv\Scripts\activate
     ```
   - **Linux / macOS:**
     ```bash
     source venv/bin/activate
     ```

4. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## 🚀 Запуск

### 1. Запусти сервер

```bash
python server.py
```

### 2. Запусти клиент

```bash
python client.py
```

Для игры на 2–3 человека запусти несколько клиентов на разных устройствах или в отдельных окнах терминала.

> По умолчанию сервер слушает `[IP:порт, например 127.0.0.1:5000]`.  
> Чтобы изменить адрес или порт, отредактируй константы в `server.py` и `client.py`.

## 🏗️ Архитектура

Проект использует **клиент-серверную модель**:

- **Сервер** хранит истинное состояние игры, обрабатывает ввод игроков и рассылает обновления.
- **Клиент** отправляет на сервер свои действия и отрисовывает полученное состояние.
- Обмен данными происходит через **UDP** (для скорости) в формате **JSON**.
- Для плавности движения удалённых игроков используется **интерполяция**.
